## Tech Debt

### Phase 1: Core Pipeline
- **RESOLVED (Phase 7):** `python-sane` is now a mandatory dependency in `pyproject.toml`. Requires `libsane-dev` (Debian) or `sane-backends-devel` (RHEL/Fedora) system headers. Dockerfile runtime stage has `libsane`. README documents the requirement.
- Human verification needed: physical scanner discovery and full E2E pipeline with real hardware

### Phase 3: Web UI
- Starlette `TemplateResponse` deprecation (13 warnings) — `name` should be second positional arg, `request` first. Functional today but will break on Starlette major version bump.
- Human verification needed: CDN-loaded PicoCSS/HTMX rendering and live polling in real browser

### Cross-Phase
- `FeederEmptyError` and `ConfigError` caught by bare `except Exception` in `worker._run()` — error type not distinguished in `JobState`, only in error message text. UX clarity issue, not data loss.
- UX timing gap in manual duplex flip flow — POST to `/api/flip/continue` returns template still showing `AWAITING_FLIP` for up to 1 polling cycle (1s) before worker transitions state.

**Total: 6 tech debt items across 3 categories. None are blockers.**
