2. **src/saneless/web/cache.py** -- `MetadataCache` class:
   - `__init__(self, ttl: int = 60) -> None`: Store `_ttl` (seconds), `_store: dict[str, tuple[float, list[dict[str, object]]]]` empty dict
   - `get(self, key: str) -> list[dict[str, object]] | None`: Check if key exists in `_store`. If `time.monotonic() - ts < self._ttl`, return data. Else return None.
   - `set(self, key: str, data: list[dict[str, object]]) -> None`: Store `(time.monotonic(), data)` at key.
   - `invalidate(self, key: str) -> None`: `self._store.pop(key, None)`
   - Import `time`. Add `__all__ = ["MetadataCache"]`. Google-style docstrings on class and all methods.

3. **src/saneless/web/app.py** -- `create_app()` factory:
   - Imports: `contextlib.asynccontextmanager`, `collections.abc.AsyncIterator`, `pathlib.Path`, `fastapi.FastAPI`, `fastapi.staticfiles.StaticFiles`, `fastapi.templating.Jinja2Templates`

4. **src/saneless/web/routes.py** -- All HTTP route handlers using `APIRouter`:
   ```python
   router = APIRouter()
   ```

   Routes to implement:

   a) `GET /` -- Page route:
      - Reads `request.app.state.settings.profiles` for profile names
      - Reads tags/correspondents from cache (or fetches fresh via paperless client)
      - **CRITICAL: Wrap `get_tags()` / `get_correspondents()` calls in try/except (catching `Exception`) and return `[]` on any error.** This ensures the page loads even when paperless-ngx is unreachable, satisfying UI-01. Log the error at warning level.
      - Gets current/latest job from job_store
      - Gets recent jobs via `job_store.list_recent(limit=50)`
      - Returns `templates.TemplateResponse("index.html", {...})`

   b) `GET /health` -- Health endpoint (HLTH-01, HLTH-02):
      - Check `request.app.state.worker.is_alive`
      - If alive: return `{"status": "ok"}`
      - If not: return `JSONResponse(status_code=503, content={"status": "error", "detail": "worker thread is down"})`

   c) `POST /api/scan` -- Start scan (form data):
      - Parameters: `profile: str = Form(...)`, `title: str = Form(default="")`, `tags: list[int] = Form(default=[])`, `correspondent: int | None = Form(default=None)`
      - If title is empty, generate: `f"Scan {datetime.now(tz=UTC).strftime('%Y-%m-%d %H:%M')}"`
      - Create job via `job_store.create_job(profile=profile, title=title, tags=tags, correspondent=correspondent)`
      - Submit to worker: `worker.submit(job)`
      - Return status partial: `templates.TemplateResponse("partials/status.html", {"request": request, "job": job})`

   d) `GET /api/jobs/current/status` -- Status polling:
      - Get `worker.current_job_id`. If set, `job_store.get_job(current_job_id)`.
      - If no current job, get latest: `jobs = job_store.list_recent(limit=1)`, use first if exists.
      - Return status partial template.

   e) `GET /api/tags` -- Tag dropdown options:
      - Try cache.get("tags"). If None, fetch via `paperless.get_tags()`, cache.set("tags", data).
      - **Wrap fetch in try/except, return empty list on error, log warning.**
      - Return tags partial template.

   f) `GET /api/correspondents` -- Correspondent dropdown options:
      - Same pattern as tags with key "correspondents" and `paperless.get_correspondents()`.
      - **Wrap fetch in try/except, return empty list on error, log warning.**
      - Return correspondents partial template.

   g) `POST /api/cache/invalidate` -- Cache invalidation (UI-08):
      - Query param: `resource: str`
      - `cache.invalidate(resource)`
      - If resource == "tags": redirect to `GET /api/tags` (return tags partial)
      - If resource == "correspondents": redirect to `GET /api/correspondents`

   h) `GET /api/jobs/history` -- Job history partial:
      - `jobs = job_store.list_recent(limit=50)`
      - Return history partial template.

   i) `POST /api/flip/continue` -- Continue manual duplex:
      - `worker.continue_flip()`
      - Return status partial (job will transition from AWAITING_FLIP to SCANNING).

   j) `POST /api/flip/abort` -- Abort manual duplex:
      - `worker.abort_flip()`
      - Return status partial.

   All route handlers: include `request: Request` parameter, access app.state for dependencies, use `request.app.state.templates` for template rendering. All need Google-style docstrings.

   Helper function `_get_cached_or_fetch(cache, paperless, resource)` to DRY up tag/correspondent fetching:
   - `data = cache.get(resource)`. If None, try fetch from paperless (getattr pattern or if/else on resource name). **Wrap in try/except, return `[]` on any exception, log at warning level.** If fetch succeeds, cache.set, return data.
