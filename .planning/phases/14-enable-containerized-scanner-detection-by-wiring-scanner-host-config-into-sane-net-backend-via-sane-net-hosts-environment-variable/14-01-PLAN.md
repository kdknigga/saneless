<objective>
Wire the existing `settings.scanner.host` config value into the SANE net backend so containerized saneless can discover network scanners. When `scanner.host` is non-empty and `SANE_NET_HOSTS` is not already set externally, the application sets the environment variable before `sane.init()`.

Purpose: Docker containers cannot access USB scanners. Users need to point at a `saned` daemon or SANE-over-network scanner on the LAN via config.
Output: Working SANE_NET_HOSTS injection with tests and Docker Compose documentation.
</objective>
