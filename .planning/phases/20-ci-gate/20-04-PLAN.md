## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `gh` token → repository administration | Ruleset creation is an admin-scope write |
| Any status producer → the required-checks rule | A rule keyed only on a context string trusts whoever posts that context |
| Throwaway branch → repository | A deliberately broken commit is pushed to the remote |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
