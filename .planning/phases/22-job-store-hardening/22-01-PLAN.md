## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → `JobStore.__init__` | A SQLite file of unverified shape and provenance is opened and structurally modified automatically at process start. This is the phase's widest boundary and D-05's guard is the control on it. |
