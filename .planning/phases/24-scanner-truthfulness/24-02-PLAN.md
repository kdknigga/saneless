<objective>
Make `classify_source()` the only classification rule in `auto_profiles.py`, collapse every
hard-coded profile slug into the device's own wording, harden the slug character set, and prune the
orphans that rename creates.

Purpose: SCNR-01's "every feeder decision" includes the flatbed and Auto decisions that select
`auto_source_mode` and the `default` profile — they answer the same question from the same strings.
And N-09 is only closed when two distinct feeder sources can never collapse into one slug, which
D-14 achieves by construction rather than by special case.

Output: `source_to_slug` becomes a single-line passthrough over a hardened `_slugify`; three ad-hoc
string rules in `generate_profiles` become `classify_source` calls; `write_profiles_to_config` gains
a prune step; and the four documentation sentences that named the old slugs are corrected.

This plan runs in wave 1 in parallel with 24-01. It shares no file with it.
</objective>

## Trust Boundaries

| Boundary | Description |
