The five-behaviour contract, measured (RESEARCH.md § Finding 7):

| Action on the real `SaneDev` | Real behaviour |
|---|---|
| assign an **unknown** option name | stored silently in `__dict__`; no device call, no raise |
| assign a **bad value** to a known option (`mode="Lineart"`, `source="Nope"`) | `_sane.error: Invalid argument` |
| assign a **wrong Python type** (`resolution="banana"`) | `TypeError: SANE_FIXED requires a floating point number` |
| read/assign a button, a group, an inactive option, or a read-only attribute | `AttributeError` with a specific message |
| read a genuinely absent attribute | `AttributeError: No such attribute: <name>` |
| `multi_scan()` | returns `_SaneIterator`; **cannot raise** |

Read-only attribute names in python-sane 2.9.2: `dev`, `optlist`, `area`, `sane_signature`,
`scanner_model`.

SANE option tuple layout, 9 elements:
`(index, name, title, desc, type, unit, size, cap, constraint)`

SANE constants this plan needs (read from `_sane`, not from `sane.UNIT_STR`):
`TYPE_FIXED=2`, `TYPE_STRING=3`, `UNIT_NONE=0`, `UNIT_MM=3`, `UNIT_DPI=4`.
