## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (LAN, unauthenticated) -> new GET and POST routes | Anyone on the LAN can request the strip and press Check again |
| cached check results -> rendered HTML | Developer-constant rows cross into the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-46 | Spoofing (CSRF) | `POST /api/checks/refresh` | mitigate | `CrossOriginGuard` is app-wide middleware on every non-safe method (`web/app.py:148`); the new POST inherits it, and no per-route dependency is added. A cross-site POST test asserts the 403 rendering |
