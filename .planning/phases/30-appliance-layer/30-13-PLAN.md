<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser cookie jar -> flip authorisation decision | A client-held opaque token decides whether two buttons render and whether an answer is accepted |
| path parameter `job_id` -> job store lookup | A client-supplied identifier reaches a database query |
| running job's title -> queue line | User document text crosses into a rendered sentence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-57 | Spoofing | a forged or guessed `saneless_owner` | accept | REQUIREMENTS states the owner token is a footgun guard, not authentication, and the trusted-LAN decision stands. Residual risk is reduced by `secrets.token_urlsafe(32)` (>=128 bits of entropy) and `secrets.compare_digest`, which removes the timing question from review |
| T-30-58 | Elevation of privilege | a non-owner answering a flip | mitigate | The comparison is server-side and the buttons are not rendered; a non-owner POST is dropped and returns the current status. Two `TestClient` cookie jars prove both halves |
| T-30-59 | Information disclosure | the owner token reaching HTML or a log | mitigate | `HttpOnly`, never rendered into any template, and logs record only "matched"/"did not match". A `caplog` assertion over the whole request proves the value never appears |
| T-30-60 | Spoofing (CSRF) | cross-site flip POST carrying the cookie | mitigate | `SameSite=Lax` withholds the cookie on any cross-site POST, and `CrossOriginGuard` already refuses browser cross-site non-safe methods app-wide. The two controls are complementary and neither weakens the other |
| T-30-61 | Tampering (path traversal) | `job_id` path parameter | mitigate | Used only as a parameterised store lookup key; it never builds a filesystem path, a URL or a template name. An unknown id falls back to the current-job rendering rather than surfacing a 404 that would confirm id existence |
| T-30-62 | Tampering (XSS) | the running job's title in the queue line | mitigate | `busy_line` returns plain text and Jinja autoescapes it; an explicit `<script>`-title test asserts the escaped output |
| T-30-63 | Denial of service | a vanished owner blocking a job forever | mitigate | D-26: the Phase 25 `FlipCoordinator` bounded timeout resolves it. No second timer and no state in which the guard silently stops guarding; the absence of an override control is asserted by test |
| T-30-SC | Tampering | npm/pip/cargo installs | accept | This plan installs nothing; `hx-confirm` is present in the vendored htmx 2.0.8 bundle |
</threat_model>
