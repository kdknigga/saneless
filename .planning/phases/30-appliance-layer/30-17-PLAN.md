<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI browser -> the public internet | A Playwright context that escapes the egress gate can make real network requests |
| rendered page -> test assertions | The tests are the mechanism that proves no secret or path reaches the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-81 | Information disclosure | a browser context reaching the network in CI | mitigate | `_make_gate` is extracted to module level and every context installs it; the shared `blocked` list is asserted empty at teardown. This is the prerequisite plan 30-19's two hand-made contexts depend on (Pitfall 9) |
| T-30-82 | Information disclosure | the log file path reaching the page | mitigate | P5 asserts `page.content()` contains neither the configured log path nor `.log`, which is the browser-level proof of D-13 |
| T-30-83 | Spoofing (data) | a NULL count rendering as 0 on a real page | mitigate | P6 parametrises the three cases and asserts zero `.page-counts` elements for the NULL row |
| T-30-84 | Denial of service (test flake) | a sleep-based wait in the browser suite | mitigate | Every wait is Playwright `expect(...)` auto-waiting or a `threading.Event` handshake; a grep gate asserts the `time.sleep` count did not rise |
| T-30-SC | Tampering | npm/pip/cargo installs | accept | This plan installs nothing; Chromium 1228 is already cached and no new Playwright download step is added |
</threat_model>
