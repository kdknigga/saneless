<objective>
Restore the saned pre-probe's multi-address behaviour without giving back its bound, and stop the
host parser from manufacturing addresses nobody configured.

Purpose: plan 30-21 replaced `socket.create_connection` with a single resolve-and-dial of
`getaddrinfo(...)[0]`. `create_connection` tried every resolved address; this tries exactly one and
calls the host dead if that one fails. `getaddrinfo` is called with `flags=0`, so `AI_ADDRCONFIG`
is not set and glibc returns AAAA records on a host with no IPv6 route, and RFC 6724 puts the IPv6
address first. Measured on this machine, `localhost` resolves to `::1` then `127.0.0.1`. saned
commonly binds v4-only. So any `scanner.host` that is a *name* with both record types --
`scanner.local` via Avahi, a LAN DNS name, `localhost` for a co-located saned, a container with no
v6 route -- fails on address one, the pre-probe's `any(...)` yields False, and `_check_scanner`
returns the amber "the configured scanner host is not answering" row **without ever calling
`get_devices()`**, permanently, on an appliance that scans fine. That is a strict regression
against the pre-30-21 code, and it is pinned by a test.

Separately, the IPv6 refusal 30-21 added fires only on a blank interior segment or a rejected
character, so a *fully expanded* literal slips straight through. Measured on this machine,
`_saned_hosts('2001:db8:0:0:0:0:0:1')` returns eight entries -- `('2001', 6566)`, `('db8', 6566)`,
`('0', 6566)` five times, `('1', 6566)` -- and glibc's single-integer IPv4 form resolves the
digit-only ones: `'2001'` to `0.0.7.209`, `'99999'` to `0.1.134.159`, `'0'` to `0.0.0.0`. A
`connect()` to `0.0.0.0` on Linux reaches loopback, so the probe can report "reachable" because
something unrelated listens on port 6566 locally.

Output: a probe that tries every address the resolver returned against one shared deadline, a
parser that refuses IPv6 literals outright and never dials an all-digit segment, and a reworked
`TestSanedProbeBound` that pins the property 30-21 actually wanted.
</objective>
