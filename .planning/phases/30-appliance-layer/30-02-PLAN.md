| config file / environment -> Settings | Operator-supplied TOML and env vars cross into the process |
| paperless token -> placeholder predicate | A secret crosses into a pure function that must not retain, log or return it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-05 | Information disclosure | `is_placeholder_token` | mitigate | Takes an already-unwrapped `str`, returns only a `bool`, never logs; the acceptance criteria assert the `get_secret_value` call-site count in config.py is unchanged so no new unwrap site is created (CFG-05, N-15) |
| T-30-06 | Tampering (XSS) | `ProfileConfig.label` / `.description` | mitigate | Both are bounded with an explicit `max_length` because they are rendered into HTML; Jinja autoescape handles the content and no consumer may use `\|safe` |
| T-30-07 | Spoofing (config) | new `[web]` section | mitigate | `extra="forbid"` on `WebConfig` so a mistyped key is a loud error, not a silently ignored security-relevant default; the unknown-key test pins the error shape |
| T-30-08 | Denial of service | unbounded profile text | mitigate | `PROFILE_LABEL_MAX_LENGTH` / `PROFILE_DESCRIPTION_MAX_LENGTH` bound what reaches the page, the same control `default_title` already applies (ROBU-08) |
| T-30-SC | Tampering | npm/pip/cargo installs | accept | This plan installs nothing; RESEARCH § Package Legitimacy Audit records the phase adds no dependency |
