## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| paperless-ngx server -> check message | An upstream error page or status code must not reach the rendered row |
| operator config (URL, token, paths) -> check message | Secrets and host filesystem paths must not reach a LAN-visible page |
| scanner host (LAN) -> socket pre-probe | An arbitrary configured host string becomes a TCP connect target |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
