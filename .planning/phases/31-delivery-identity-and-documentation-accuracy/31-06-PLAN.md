           `SANELESS_SCANNER__HOST` pointing at it (`host.docker.internal` or the host's LAN IP).

| Boundary | Description |
|----------|-------------|
| documentation -> operator's deployment decisions | A page that recommends a privileged or unsupported shape becomes a real misconfiguration on a real host |
| the web UI -> the LAN | The server binds `0.0.0.0` with no authentication; whether that is safe depends entirely on the operator knowing it |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

The posture itself is Phase 26 territory and does not change here; what changes is that an operator can no longer deploy it without being told |
