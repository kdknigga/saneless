## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| store row -> rendered status area | `job.error` text written by the web layer is later rendered |
| database -> PRAGMA statement text | the probe interpolates a value read from the database |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01 | Information disclosure | `rejection_message` copy | mitigate | Every message is a developer constant; tests assert literal equality, so no format slot for input or exception text exists |
| T-26-02 | Tampering (SQL) | `_SELECT_LATEST_RUN` | mitigate | Only module constants interpolated; the category value is bound (`IS NOT ?`) |
| T-26-03 | Tampering (SQL) | `probe()` PRAGMA write | mitigate | The interpolated value is an `int` read from the same database in the same transaction; no request data reaches it |
| T-26-04 | Repudiation | rejection hidden from history | mitigate | `list_recent` is unchanged; test asserts the REJECTED row is still first in `list_recent(1)` |
| T-26-SC | Tampering | package installs | accept | No package installed by this plan |
</threat_model>
