<objective>
Make the server the single source of truth for the Scan button (ROBU-04, C-10): one include,
out-of-band re-renders on every status response, no JavaScript, and a cap on the title input.

Purpose: `app.js` reads `evt.detail.target`, which for `outerHTML` swaps is the detached pre-swap
node, so the button never re-enables; and the button's rule lives twice (Jinja and JS). Research
Pattern 5 verified in htmx 2.0.8 source that an OOB `outerHTML` replacement lands before
`hx-disabled-elt` cleanup, and that `hx-disabled-elt` inherited by the tag/correspondent selects
would re-enable a server-disabled button on 2.0.8 unless the form carries `hx-disinherit`.
The C-10 lesson applies: browser proof (B3, B5, B6, B7) is plan 26-12, which runs next.

Output: two new partials, index/base template edits, `app.js` deleted, four routes switched to the
new response template, structural tests T1-T3.
</objective>
