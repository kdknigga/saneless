<objective>
Replace the sentinel/blocking-put protocol with a stop flag, a queue shutdown and a bounded join;
make `submit()` report instead of block; convert the tests that leaned on a draining `stop()`; and
put the worker's profile reads behind one lock (C-09, N-24, D-07, D-08, D-19).

Purpose: a full queue must never hang a request thread or shutdown. Research verified that
`queue.Queue.shutdown(immediate=True)` wakes a blocked `get()` in ~0.2 ms, which keeps ~140
lifespan/worker tests fast. The guarded loop, degraded health and prune move are plan 26-06; startup
generation is 26-08. The routes consume `SubmitResult` in 26-10 and the lifespan consumes `stop()`'s
return value in 26-09; until then they ignore the return values, which still type-checks.

Output: rewritten `stop`/`submit`/`_run`, profile accessors, converted and new tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| request thread -> worker queue | untrusted LAN clients cause submits |
| lifespan/shutdown -> worker thread | shutdown must not depend on worker progress |
| request threads <-> worker thread | shared profiles mapping |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-11 | Denial of service | blocking `put` on a full queue hangs request threads (C-09) | mitigate | `put_nowait` -> `SubmitResult.QUEUE_FULL`; test asserts < 0.1 s on a full queue |
| T-26-12 | Denial of service | shutdown sentinel blocks on a full queue; unbounded join | mitigate | `Queue.shutdown(immediate=True)` + `STOP_JOIN_SECONDS` join returning bool; tests for idle wake, full queue, join expiry |
| T-26-13 | Denial of service | flip wait holds shutdown for flip_timeout_seconds | mitigate | stop() arms+aborts the live coordinator; `_status_cb` aborts when stopping; both tested through the real pipeline |
| T-26-14 | Tampering (race) | profile dict iterated while mutated across threads | mitigate | `_profiles_lock` on every read; rebinding writes; threaded test |
| T-26-15 | Repudiation | shutdown-aborted job recorded as an operator abort | mitigate | failure path writes RESTART_REASON when stopping; tested |
| T-26-SC | Tampering | package installs | accept | None |
