polling, and clear on success (ROBU-02's "a visible message", D-02, D-03, D-05, D-06); and prove on a

button is disabled while a job is active, so the setup loads the page idle and fills the queue over
HTTP afterwards. `localhost`/`127.0.0.1` are secure contexts that always send Sec-Fetch-Site, so
only a non-loopback address exercises branch 2 in a browser.
