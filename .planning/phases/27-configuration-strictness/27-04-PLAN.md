Turn `auto-profiles --force` from "replace" into "merge" (CFG-07, D-01..D-04, M-09) and route every
config rewrite through the atomic helper from plan 27-02 with UTF-8, CRLF-preserving, re-parse-guarded
output (CFG-08, D-05, D-07, D-08, M-10). Both front ends consume a structured result with one
vocabulary.

was truncate-then-write in the locale encoding. Plan 27-05 ships the directory-mount compose/docs in this
same wave (CFG-09), so the atomic write never lands without it.

Output: merge-aware writer, `ProfileWriteResult`, worker and CLI consumers, tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator-edited config file -> tomlkit parse/merge | Untrusted-shape TOML (inline sections, split tables, CRLF, non-UTF-8) is rewritten by the process |
| root container process -> host-mounted config | A rewrite can corrupt or re-own the operator's file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-write | Denial of service (corrupt config) | `write_profiles_to_config` | mitigate | `tomllib.loads` guard on the dumped text before `replace_file_atomically`; InlineTable-aware insertion; test forces invalid output and asserts the file is byte-identical |
| T-27-14 | Tampering (data loss) | `--force` over hand-written profiles | mitigate | `_is_auto_generated` gate: unflagged profiles are never mutated (D-01); owned keys only for flagged profiles (D-02/D-03); byte-identity test |
| T-27-15 | Tampering | locale-dependent re-encoding / CRLF rewrite | mitigate | bytes read + explicit UTF-8 decode, UnicodeDecodeError -> ConfigError, CRLF normalisation of added lines |
| T-27-16 | Information disclosure | OSError/ConfigError text printed by the CLI | accept | messages contain paths and errno text only, no config values; the operator running the CLI owns the file |
| T-27-17 | Denial of service | EBUSY on legacy single-file mounts | mitigate | clear ConfigError with the fix (D-08); CLI exit 2; worker keeps profiles in memory; no-op merges skip the replace entirely |
