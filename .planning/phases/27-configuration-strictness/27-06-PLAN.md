<objective>
Rework the CLI entry point: settings load lazily per command so `--help` never needs a valid config
(CFG-10, N-25), logging is configured inside the error handling (M-21), `-v` really means DEBUG for
saneless's own loggers (CFG-04), the CFG-11 startup line is emitted once, the loader's rendered
ConfigError is printed without a doubled prefix, and `scan --title` becomes optional through the
shared title rule (CFG-06 CLI half, D-16).

Purpose: Click runs the group callback before parsing a subcommand's `--help` and `ctx.resilient_parsing`
is False there (verified), so only lazy loading satisfies CFG-10.

Output: cli.py and logging_config.py changes, tests.
</objective>

| T-27-21 | Information disclosure | tracebacks on logging setup failure | mitigate | `configure_logging` inside the same try; any exception -> one-line message, exit 2, no traceback (test asserts SystemExit) |

| T-27-24 | Tampering | control characters in the resolved title echoed as `Done: ...` | accept | the title is the operator's own input on their own terminal; profile titles are length-bounded (plan 27-01) |
