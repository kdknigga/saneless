       - `class PaperlessClient`:
         - `__init__(self, url: str, token: str, consume_dir: str = "", max_retries: int = 3)`:
           - Creates `httpx.Client(base_url=url.rstrip("/"), headers={"Authorization": f"Token {token}"}, timeout=30.0)`
           - Stores consume_dir and max_retries
         - `upload_document(self, pdf_path: Path, title: str, tags: list[int] | None = None, correspondent: int | None = None, created: str | None = None) -> str`:
           - Builds form data: [("title", title)], plus optional ("created", created), ("correspondent", str(correspondent))
           - Tags as repeated fields: for each tag_id, append ("tags", str(tag_id))
           - Retry loop: for attempt in range(self._max_retries):
             - try: POST /api/documents/post_document/ with files={"document": open(pdf_path, "rb")} and data=fields
             - On httpx.ConnectError or httpx.TimeoutException: if last attempt, check consume_dir fallback. Otherwise sleep(2**attempt) and continue.
             - On httpx.HTTPStatusError with 4xx: raise PaperlessError immediately (no retry)
             - On success: return response.json() (task UUID)
           - If consume_dir set and all retries failed: shutil.copy2(pdf_path, Path(consume_dir) / pdf_path.name), return "fallback"
           - If no consume_dir: raise PaperlessError("Upload failed after {max_retries} retries")
         - `poll_task(self, task_id: str, timeout: int = 300) -> dict`:
           - delay=1.0, elapsed=0.0
           - Loop while elapsed < timeout:
             - GET /api/tasks/ with params={"task_id": task_id}
             - If 200 and response is non-empty list: check tasks[0]["status"]
             - If status in ("SUCCESS", "FAILURE"): return task dict
             - sleep(delay), elapsed += delay, delay = min(delay * 2, 30.0)
           - Return {"status": "TIMEOUT", "task_id": task_id}
         - `test_connection(self) -> str`:
           - try: GET /api/
           - If status 401 or 403: return "token_rejected"
           - If 200: return "connected"
           - On httpx.ConnectError: return "unreachable"
         - `close(self) -> None`: closes httpx.Client
       - `__all__ = ["PaperlessClient"]`
