    1. Create `src/saneless/job.py`:
       - `class JobState(str, Enum)`: PENDING, SCANNING, ASSEMBLING, UPLOADING, DONE, ERROR
       - `@dataclass class Job`:
         - id: str (UUID)
         - profile: str
         - title: str
         - state: JobState = JobState.PENDING
         - error: str | None = None
         - created_at: datetime (timezone-aware, default now)
         - tags: list[int] = field(default_factory=list)
         - correspondent: int | None = None
       - `class JobStore`:
         - `__init__(self, db_path: str = ":memory:")`: opens sqlite3 connection, creates jobs table with columns: id TEXT PRIMARY KEY, profile TEXT, title TEXT, state TEXT, error TEXT, tags TEXT (JSON), correspondent INTEGER, created_at TEXT
         - `create_job(self, profile: str, title: str, tags: list[int] | None = None, correspondent: int | None = None) -> Job`: inserts row, returns Job
         - `get_job(self, job_id: str) -> Job | None`: fetches by id
         - `update_state(self, job_id: str, state: JobState, error: str | None = None) -> None`: updates state and optionally error
         - `close(self) -> None`: closes connection
       - `__all__ = ["Job", "JobState", "JobStore"]`

    2. Create `src/saneless/pipeline.py`:
       - `def run_pipeline(scanner: ScannerBackend, paperless: PaperlessClient, settings: Settings, profile_name: str, title: str, tags: list[int] | None = None, correspondent: int | None = None, status_callback: Callable[[str], None] | None = None) -> dict`:
         - Resolve profile from settings.profiles[profile_name] (raise ConfigError if not found)
         - Create `tempfile.TemporaryDirectory(dir=settings.output.tmp_dir)` as context manager
         - status_callback("Scanning...")
         - Determine device_id: settings.scanner.device (or raise ConfigError if empty and no device pinned)
         - Create ScanSettings from profile (source, resolution, mode)
         - Collect images from scanner.scan_pages(device_id, scan_settings) into list
         - status_callback("Assembling PDF...")
         - Call assemble_pdf(images, tmp_dir_path) -> pdf_path
         - status_callback("Uploading to paperless-ngx...")
         - created = datetime.now(tz=timezone.utc).isoformat()
         - task_uuid = paperless.upload_document(pdf_path, title, tags, correspondent, created)
         - If task_uuid != "fallback": result = paperless.poll_task(task_uuid, timeout=settings.output.paperless_task_timeout)
         - Else: result = {"status": "FALLBACK", "path": str(consume_dir_path)}
         - status_callback(f"Done: {title}")
         - Return result
         - TemporaryDirectory context manager ensures cleanup on success and error
       - `__all__ = ["run_pipeline"]`

    3. Create `src/saneless/worker.py`:
       - `class ScanWorker`:
         - `__init__(self, scanner: ScannerBackend, paperless: PaperlessClient, settings: Settings, job_store: JobStore)`:
           - Creates `queue.Queue(maxsize=10)`
           - Stores references to scanner, paperless, settings, job_store
           - Creates daemon thread targeting `_run` method
         - `start(self) -> None`: starts the thread
         - `stop(self) -> None`: puts sentinel None on queue, joins thread with timeout=5
         - `submit(self, job: Job) -> None`: puts job on queue
         - `_run(self) -> None`:
           - Loop: get item from queue, if None break
           - job_store.update_state(job.id, SCANNING)
           - try: run_pipeline(scanner, paperless, settings, job.profile, job.title, job.tags, job.correspondent, status_callback=lambda msg: logger.info(msg))
           - job_store.update_state(job.id, DONE)
           - except Exception as e: job_store.update_state(job.id, ERROR, error=str(e)), logger.error(f"Job {job.id} failed: {e}")
       - `__all__ = ["ScanWorker"]`

    4. Create `tests/test_worker.py` and `tests/test_pipeline.py` with all behaviors listed above.
