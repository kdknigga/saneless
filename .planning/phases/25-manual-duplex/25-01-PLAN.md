<objective>
Give a profile its own `duplex` field so `source` stops carrying a scanning strategy, translate the
legacy `source = "Manual Duplex"` marker at config load, and add the flip timeout knob.

Purpose: DPLX-01 and DPLX-02. This is the foundation every later plan reads. Nothing consumes
`duplex` yet — `pipeline._is_manual_duplex` still drives the strategy — so this plan changes **no
runtime behaviour** and the suite stays green throughout.

Output: `ProfileConfig.duplex`, `_is_legacy_manual_duplex_source`, a before-validator, a
deprecation field-validator, `OutputConfig.flip_timeout_seconds`, and a module logger for
`saneless.config`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator TOML / env → `Settings` | A file and `SANELESS_PROFILES__<NAME>__*` env vars the operator controls cross into typed config |
| config values → application log | A profile key and a `source` string are interpolated into a WARNING record |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | Tampering (input) | `ProfileConfig.duplex` | mitigate | `Literal["none","hardware","manual"]` — pydantic rejects any fourth value at load. No hand-rolled parsing. ASVS V5 |
| T-25-02 | Tampering (input) | `OutputConfig.flip_timeout_seconds` | mitigate | Typed `int`; pydantic rejects a fractional float in lax mode. No string parsing |
| T-25-03 | Tampering (log integrity) | `warn_on_legacy_duplex_source` | mitigate | `%`-style lazy args interpolate the operator-supplied profile name and source string through the logging formatter, never an f-string. Ruff's `G` family is in `select` and enforces this |
| T-25-04 | Information Disclosure | the deprecation WARNING | accept | `ProfileConfig` carries no credential (the Paperless token lives on `PaperlessConfig`), so the message cannot leak a secret. Verified by reading the model |
| T-25-05 | Denial of Service (self-inflicted) | `flip_timeout_seconds = 0` | accept | The config file is operator-owned and already able to break the install a dozen ways; `0` is deliberately *useful* — it is the zero-cost test seam plans 25-03 and 25-05 depend on |
| T-25-SC | Tampering | npm/pip/cargo installs | N/A | This phase installs nothing. RESEARCH.md § Package Legitimacy Audit records an empty table with the reason |
