coordinator-less manual-duplex run before any SANE contact, and replace the `isinstance` type-switch
with a total `match`.

`"manual" in source and "duplex" in source`; if it ever drifts from `pipeline._is_manual_duplex` the
pipeline skips the wait — which is exactly the C-02 failure. This plan leaves one reader.

Output: one strategy read, one refusal guard, one total dispatch, and two grep gates that prove it.
</objective>

breaks ~10 pipeline tests at once. It does not break them here, because plan 25-03's
`PipelineRequest` field swap already forced every duplex test onto
`flip_coordinator=AlwaysContinueFlipCoordinator()`. By the time this guard lands, every test already
supplies one. If you find a duplex test without a coordinator, plan 25-03 was incomplete — fix it
here rather than weakening the guard.
