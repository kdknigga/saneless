## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest (+ pytest-playwright 0.7.2, pytest-timeout) |
| **Config file** | `pyproject.toml` `[tool.pytest.ini_options]` (strict markers, `filterwarnings = error`, timeout 60) |
| **Quick run command** | `uv run pytest tests/test_browser.py -m browser -q` |
| **Full suite command** | `uv run pytest -m "not browser" -q && uv run pytest -m browser -q` |
| **Static gate** | `uv run ruff check . && uv run ruff format --check . && uv run ty check && uv run pyrefly check src tests` |
| **Estimated runtime** | ~60 seconds (non-browser suite ~30s, browser suite ~30s) |

---

## Sampling Rate

- **After every task commit:** static gate + `uv run pytest -m "not browser" -q`; DARK tasks also run `uv run pytest tests/test_browser.py -m browser -q`
- **After every plan wave:** full suite (browser included). The pre-merge-commit hook itself now runs the full type check.
- **Before `/gsd-verify-work`:** full suite green; D-07 demo transcript present in SUMMARY; GATE-03 grep lists only justified lines; ROADMAP D-15/D-16 greps hit
- **Max feedback latency:** 60 seconds
