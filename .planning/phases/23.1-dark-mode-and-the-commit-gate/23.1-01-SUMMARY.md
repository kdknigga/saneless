## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] T2's `context` parameter collided with a pytest-playwright fixture**

- **Found during:** Task 1, on the first RED run.
- **Issue:** The plan specified a parametrize argument named `context`. pytest-playwright already defines a `context` fixture (the `BrowserContext` that `page` is built from). Parametrizing that name replaced the fixture with a string, so all 12 T2 cases ended as `ERROR ... AttributeError: 'str' object has no attribute 'new_page'` instead of running. Errors, not assertion failures, would have made the RED gate meaningless.
- **Fix:** Renamed the Python parameter to `placement`, with a comment recording why. The JS probe still receives `{cls, context}`, so `_PROBE_CONTEXT_CONTRAST` matches the plan's contract unchanged.
- **Files modified:** `tests/test_browser.py`
- **Commit:** `58c344a`

After the rename, RED reported exactly the 4 assertion failures the plan called for.
