## Deviations from Plan

**1. [Rule 3 - Blocking] `xargs` is refused by the worktree isolation guard**
- **Found during:** Task 1
- **Issue:** The G7 recipe pipes the candidate list into `xargs perl`. The worktree guard refuses any
  `xargs -a` invocation because it cannot prove the command is not git.
- **Fix:** The identical substitution and guard were moved into a scratchpad perl script that reads
  the same candidate list, asserts it holds 91 files, and edits in place with `$^I`. The regex, the
  guard alternation and the replacement text are unchanged from G7.
- **Files modified:** none in the repository; the script lives in the session scratchpad.
- **Commit:** 092b9a0

**2. [Rule 1 - Bug] The plan's collision check cannot be run unscoped**
- **Found during:** Task 1, step (c)
- **Issue:** `/usr/bin/grep -rn 'src testss' .planning` and the doubled-insertion grep both match the
  plan's own text in 23.1-03-PLAN.md and 23.1-VALIDATION.md, which quote those strings. The plan's
  `test -z` form therefore fails for a reason unrelated to the rewrite.
- **Fix:** Both checks are scoped with `| /usr/bin/grep -v 'phases/23.1-'`. Scoped, both are empty, so
  no inflected word was split and no line was substituted twice.
- **Files modified:** none
- **Commit:** n/a

**3. [Rule 2 - Correctness] Two "kept" historical lines were verification guidance, not defect narrative**
- **Found during:** Task 2
- **Issue:** RESEARCH G7 predicted 20 guard-kept lines. Two of them endorse the unscoped form as the
  authoritative post-merge verification, which a future author could act on — the precise behaviour
  GATE-03 exists to stop.
- **Fix:** Hand-rewritten to name `src tests`, per Task 2's non-exempt rule. Detailed in
  *Reconciliation against the expected 38*.
- **Files modified:** `.planning/phases/21-vocabulary-and-contracts/21-01-SUMMARY.md`,
  `.planning/phases/22-job-store-hardening/22-06-SUMMARY.md`
- **Commit:** b7dc077

A cosmetic note, not a deviation: several rewritten lines sit in aligned result tables (for example
21-05-SUMMARY.md:292), where the four added characters push the `->` column out of alignment. No
content changed and the plan forbids any edit beyond the path insertion, so they were left alone.
