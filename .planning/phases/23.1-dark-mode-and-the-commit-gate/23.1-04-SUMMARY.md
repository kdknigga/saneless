## Notes for the verifier

The orchestrator's `git merge --no-ff` of this worktree is the **first live pre-merge-commit run**
in this repository. Expect `ty type checker (full)` and `pyrefly type checker (full)` to appear in
the merge output and to pass — this worktree was left type-clean deliberately. If that merge ever
exits 1, it leaves `MERGE_HEAD` behind and GSD misreports it as a conflict; the recovery is
`git merge --abort`, not finishing the merge with `git commit` (which would fall through the D-05
src-only path).
