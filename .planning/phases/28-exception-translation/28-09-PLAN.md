<objective>
Put one last-resort handler around every CLI command (EXC-02): a `click.Group` subclass whose
`invoke` turns every saneless error into one line and its D-07 exit code, a cancel or Ctrl-C into
130, a job database saneless cannot use into exit 2, and anything that is not a saneless type into
exit 5 with the traceback in the log -- while leaving click's `--help`, usage errors and
`ClickException`s alone. JobStore's open path is translated so an unreadable database arrives at
the guard as a `StorageError` rather than a raw sqlite3 error.

Purpose: success criterion 2 (bad config, broken scanner, unreachable Paperless, unassemblable PDF
each print one line and exit non-zero) and D-06's "no user ever sees a traceback".
Output: cli.py guard and exit codes, logging_config.py return value, job.py open-time StorageError, tests. `require_sane` calls and
`serve`'s exit 2 are plan 28-12; the flip-prompt cancel classification is plan 28-11.
</objective>
