URL, every transport failure, a non-JSON body and a consume-directory copy failure all end as
`PaperlessError` with the base URL and the original text (D-08). Widen the retry set to every
transient `TransportError` while failing a malformed URL fast (D-10), and replace both body
renderers with one that reduces Paperless error bodies to one line (D-09).

connection skips the fallback and escapes raw".
Output: paperless.py upload-side changes, tests. Poll continuation, duplicate wording and the
metadata endpoints are plan 28-10.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Paperless / reverse proxy -> client | Untrusted response bodies and connection behaviour |
| client -> error message -> job store, web UI, terminal | Rendered text persists and is displayed |
| config -> Authorization header | The API token lives only in the header |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-19 | Denial of service / UI spoofing | upstream body (5 KB HTML, M-17) flooding job.error | mitigate | `_render_error_body` returns one line of at most 200 characters plus ellipsis; full body only at DEBUG; tests pin length and no newline |
| T-28-20 | Information disclosure | token in wrapped messages | mitigate | Messages interpolate only `self._base_url` and `describe(exc)`; httpx exception text carries no headers (measured); test asserts the token is absent from the InvalidURL message; `-v` does not raise httpx to DEBUG (T-27-23) |
| T-28-21 | Information disclosure | full body at DEBUG | accept | Operator-controlled log at DEBUG only; bodies are Paperless's own error text, not credentials |
| T-28-22 | Denial of service | retrying a malformed URL three times with backoff | mitigate | `UnsupportedProtocol` caught before `TransportError`; test asserts one call and no sleep |
| T-28-23 | Tampering (duplicate document) | retry after a lost response | accept | User-accepted risk (D-10 amendment): a duplicate is easy to delete, a lost scan is not; documented in the docstring and in plan 28-14's docs |
| T-28-24 | Tampering (terminal escape) | rendered body in the CLI line | mitigate | `" ".join(text.split())` removes newlines, tabs and other whitespace control characters so the body cannot forge extra CLI lines; the web template autoescapes `job.error` |
