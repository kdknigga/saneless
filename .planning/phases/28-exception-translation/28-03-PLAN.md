<objective>
Give zero pages a truthful message at the pipeline boundary (EXC-03). An empty batch says
"No pages were scanned" before empty-page detection or `assemble_pdf` can misreport it, and "All
pages were blank" is used only when detection really removed every page.

Purpose: N-06: today an empty batch reads "All pages were detected as empty" (detection on) or leaks
img2pdf's bare `ValueError` (detection off, or an empty duplex half).
Reconciliation with Phase 24 D-03 (resolved by research, no user conflict): the SANE backend never
returns an empty batch -- an empty feeder raises `FeederEmptyError("No paper detected in feeder")`
and that stays; "No pages were scanned" is the pipeline's contract check against any
`ScannerBackend`, reachable from other backends and fakes.
Output: `_require_pages`, reworded `_drop_empty_pages`, tests.
</objective>
