<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config file on disk -> loader | Operator-controlled file that holds the Paperless token |
| loader exception -> terminal / log | ConfigError text is printed and may be logged with its chain |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-05 | Information disclosure | `TOMLDecodeError.doc` / `UnicodeDecodeError.object` | mitigate | Render only `lineno`, `colno`, `msg`, `start`, `reason`, `strerror`; never `doc` or `object`; test writes a token into a broken file and asserts it is absent from `str`, `repr` and the cause's `str` |
| T-28-06 | Tampering (terminal escape) | tomllib message containing a key path with control characters | mitigate | `exc.msg` passed through `_escape_name`; test asserts `\x1b` appears escaped |
| T-28-07 | Information disclosure | ValidationError chain | mitigate | Keep `from None` for validation failures (existing `_assert_value_absent` tests stay green) |
| T-28-08 | Tampering | partially rewritten config after a parse failure | mitigate | `_read_config` raises before any write; test asserts file bytes unchanged |
</threat_model>
