<objective>
Classify an explicit operator abort at the flip prompt as a cancellation end to end (EXC-04): the
pipeline raises `ScanCancelledError` for a real abort and `ScanError` for a broken prompt or a
timeout (D-02), the CLI exits 130 for `n` / Ctrl-D / Ctrl-C (D-03), and the web Abort button ends
the job CANCELLED.

Purpose: N-08 -- a user abort was recorded as a scanner failure. The worker (plan 28-07) and the
CLI guard (plan 28-09) already handle `ScanCancelledError`; this plan makes the pipeline raise it
and flips the tests that pinned the old behaviour.
Output: pipeline.py flip classification, ClickFlipCoordinator cause, test updates across three suites.
</objective>
