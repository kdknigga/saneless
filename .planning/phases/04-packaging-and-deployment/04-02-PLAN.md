    1. Create `.github/workflows/` directory if it does not exist.

    2. Create `.github/workflows/release.yml` with three jobs triggered on `v*` tag push:

       **Job 1: test**
       - runs-on: ubuntu-latest
       - Steps: checkout@v5, setup-uv@v7, `uv sync`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run pytest`
       - Note: Do NOT include `uv run ty check` or `uv run pyrefly check` in CI -- these require Python 3.14 which may not be available in ubuntu-latest runners. Only ruff + pytest.

       **Job 2: publish-pypi**
       - needs: test
       - runs-on: ubuntu-latest
       - environment: pypi
       - permissions: id-token: write (CRITICAL for OIDC trusted publishing)
       - Steps: checkout@v5, setup-uv@v7, `uv build`, pypa/gh-action-pypi-publish@v1.12

       **Job 3: publish-docker**
       - needs: test
       - runs-on: ubuntu-latest
       - permissions: contents: read, packages: write
       - Steps: checkout@v5, docker/login-action@v3 (registry: ghcr.io, username: `${{ github.actor }}`, password: `${{ secrets.GITHUB_TOKEN }}`), docker/metadata-action@v5 (images: `ghcr.io/${{ github.repository }}`, tags: `type=semver,pattern={{version}}` + `type=raw,value=latest`), docker/build-push-action@v6 (context: ., push: true, tags+labels from metadata step)

    3. The workflow YAML must use exact action versions: actions/checkout@v5, astral-sh/setup-uv@v7, pypa/gh-action-pypi-publish@v1.12, docker/login-action@v3, docker/metadata-action@v5, docker/build-push-action@v6.
