<objective>
Add the `auto_source_mode` config field to ProfileConfig and ScanSettings, wire it through the pipeline, and implement the conditional routing in scan_pages() so that "Auto" sources can be configured as flatbed or ADF.

Purpose: Enables users with scanners that advertise "Auto" as a source to control whether it routes to single-page flatbed or multi-page ADF scanning behavior.
Output: Working config-to-scan routing for auto_source_mode, with tests proving both paths.
</objective>
