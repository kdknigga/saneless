<objective>
Switch the scanner contract: `ScanBatch.pages` becomes an ordered tuple of `PageRecord`,
`scan_pages` takes a `PageSink`, `ScannerBackend` gains `close()`, and `SaneBackend` acquires one
page at a time and hands it straight to the sink. Build the conftest migration seam in the same
plan, because it is the lever the four test-migration plans pull.

Purpose: HARD-01's memory bound is only real once the backend stops holding a list of images.
Output: the switched contract in `scanner/base.py`, a sink-driven `sane_backend.py`, and the
`tests/conftest.py` factories every downstream stub will use.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SANE device → process memory | An arbitrary-size image crosses into the process once per page |
| scanner backend → pipeline-owned spool | The backend hands off ownership of each page at `sink.add` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-05 | Denial of service | `_acquire_pages` loop | mitigate | `_MAX_ADF_PAGES` (500) still applies per `scan_pages` call and is untouched by this plan; the sink adds the per-page free-space check from plan 01 |
| T-29-06 | Tampering | `_validate_page_image` byte-count change | mitigate | The width-times-height-times-bands formula is exact for `L` and `RGB`, the only modes `snap()` can produce; the mode `"1"` caveat is recorded in the docstring so the `_MIN_PAGE_BYTES` floor is not silently loosened (Pitfall 7) |
| T-29-07 | Information disclosure | `Scanner error on page N` messages | accept | Messages name the page number and the device id only; `describe()` collapses third-party text to one line. No credential is in scope (ASVS V7) |
| T-29-08 | Spoofing | `StubScannerBackend` in tests | accept | Test-only; subclassing the ABC is what makes the type checkers catch a contract drift, which is the point |
</threat_model>
