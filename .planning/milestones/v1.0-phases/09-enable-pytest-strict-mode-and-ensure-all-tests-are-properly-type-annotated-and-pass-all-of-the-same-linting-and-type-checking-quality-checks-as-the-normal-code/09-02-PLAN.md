This is a large mechanical task. Process every test file applying these three transformations:

**1. Return type annotations (~211 functions missing them):**
- All test functions: `-> None` (tests don't return values)
- All fixtures without yield: return the concrete type (e.g., `-> Settings`, `-> Path`, `-> MagicMock`, `-> Image.Image`)
- All fixtures with yield: `-> Iterator[ConcreteType]` (import `Iterator` from `collections.abc`)
- `__init__` methods: `-> None`
- Common pytest parameter types to use:
  - `tmp_path: Path` (from pathlib)
  - `monkeypatch: pytest.MonkeyPatch`
  - `capsys: pytest.CaptureFixture[str]`
  - `request: pytest.FixtureRequest`
  - `tmp_path_factory: pytest.TempPathFactory`

**File-by-file return annotation counts (approximate):**
- conftest.py: 11 fixtures need return types
- test_cli.py: 52 functions need `-> None`

- test_pipeline.py: 28 functions need `-> None`

**2. Parameter type annotations (~389 parameters missing them):**
- Annotate every function/method parameter with its concrete type
- Use precise types per CONTEXT.md decision: actual types, not MagicMock/Any (except where mock IS the actual value -- then `MagicMock` is correct)
- Fixture parameters use the fixture's return type
- The `self` parameter does NOT need annotation (PEP convention)

**3. Docstrings (~38 functions missing them):**
- Add single-line docstrings to every public function, class, and module missing one
- Format: `"""Brief description of what this tests or provides."""`
- Files with most gaps: test_paperless.py (20), test_worker.py (11), test_scanner.py (4)

**4. Move lazy imports to top-level (~77 occurrences across 10 files):**
- Move standard library imports (pathlib, json, io, etc.) to top of file
- Move project imports (from saneless.* import ...) to top of file
- Move third-party test utilities (from unittest.mock import ...) to top of file
- **Keep lazy with per-line `# noqa: PLC0415 — [justification]` ONLY if:**
  - Import depends on monkeypatch being active first (e.g., `mock_sane_module` fixture patches sys.modules before import)
  - Import triggers side effects at module load time
- Largest files: test_cli.py (29 lazy imports), test_scanner.py (20), test_worker.py (14)
- For test_scanner.py: imports of `SaneBackend` inside tests that use `mock_sane_module` fixture MUST stay lazy because the fixture monkeypatches `sys.modules["sane"]` before the import. Add `# noqa: PLC0415 -- import after sane module monkeypatch` to each.
- For test_cli.py: most lazy imports of Click test utilities and saneless modules can move to top-level. Only imports that depend on fixture-patched state must stay lazy.
