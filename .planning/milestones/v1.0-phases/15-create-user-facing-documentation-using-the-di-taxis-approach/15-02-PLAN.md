**docs/how-to/scanner-host-discovery.md** (per D-07 item 5):
- Title: `# Scanner Host Discovery (Containers)`
- Prerequisites (per D-16): Network scanner, saneless running in Docker
- Problem statement: Docker containers can't see USB scanners; network scanners need SANE's net backend
- Solution: Set `scanner.host` in config or `SANELESS_SCANNER__HOST` env var
- How it works: saneless sets `SANE_NET_HOSTS` before initializing SANE (per Phase 14 decision)
- Method 1 -- config.toml:
  ```toml
  [scanner]
  host = "192.168.1.50"
  ```
- Method 2 -- environment variable:
  ```yaml
  # docker-compose.yml
  environment:
    - SANELESS_SCANNER__HOST=192.168.1.50
  ```
- Multiple hosts: colon-separated `host = "192.168.1.50:192.168.1.51"`
- Priority: externally-set SANE_NET_HOSTS takes priority over config (per Phase 14 decision)
- Verify: `docker exec saneless saneless devices` should list the network scanner
- Troubleshooting: firewall rules (SANE uses TCP port 6566), scanner not in net mode
