         ```python
         # Set scan area geometry for paper size constraint (D-01)
         geometry_set = False
         if settings.paper_size != "full":
             dims = PAPER_SIZES_MM.get(settings.paper_size)
             if dims:
                 width_mm, height_mm = dims
                 try:
                     dev.tl_x = 0.0
                     dev.tl_y = 0.0
                     dev.br_x = width_mm
                     dev.br_y = height_mm
                     geometry_set = True
                     logger.info(
                         "Scan area set to %s: %.1f x %.1f mm",
                         settings.paper_size,
                         width_mm,
                         height_mm,
                     )
                 except Exception:
                     logger.warning(
                         "Scanner does not support geometry options, "
                         "will crop after scanning",
                     )
         ```
       - After yielding images, apply crop fallback when geometry was NOT set. This requires restructuring the yield logic slightly:
         - For flatbed path: after `image = dev.snap()`, before `yield image`, add:
           ```python
           if settings.paper_size != "full" and not geometry_set:
               image = crop_to_paper_size(image, settings.paper_size, settings.resolution)
           ```
         - For ADF path (`_scan_adf_pages` yields pages): the crop must be applied to each yielded page. Since `_scan_adf_pages` is a separate method, the cleanest approach is to wrap the yield in scan_pages:
           - Replace `yield from self._scan_adf_pages(dev)` with an explicit loop:
             ```python
             for page in self._scan_adf_pages(dev):
                 if settings.paper_size != "full" and not geometry_set:
                     page = crop_to_paper_size(page, settings.paper_size, settings.resolution)
                 yield page
             ```
