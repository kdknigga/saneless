    - Test: TOML with unknown top-level section like `[bogus]` raises ConfigError with message listing valid top-level sections (scanner, paperless, output, profiles)
    - Test: Env var `SANELESS_PROFILES__DEFAULT__TITLE=EnvTitle` sets default_title_template to "EnvTitle" when no config file present
    - Test: Valid TOML with env var override still works (existing test_env_var_override passes)

  <action>
    1. In ProfileConfig (BaseModel), add `title` as a Pydantic field alias for `default_title_template`. Use `Field(alias="title", default="")` on `default_title_template`, and set `model_config = ConfigDict(populate_by_name=True)` on ProfileConfig so both `title` and `default_title_template` work as field names in TOML and code.

    2. In `load_settings()`, wrap each `Settings(...)` call in a try/except that catches `pydantic.ValidationError`. Inspect the error's `.errors()` list for `type == "extra_forbidden"`. If found:
       - Extract the extra field name(s) from the error details (the `loc` tuple)
       - Build a user-friendly message like: `"Unknown config section '{field}'. Valid top-level sections: scanner, paperless, output, profiles. Did you mean [profiles.{field}]?"`
       - Raise `ConfigError(message)` from the original error
       - If the validation error is NOT about extra fields, re-raise it as-is

    3. Import `ConfigError` from `saneless.exceptions` and `ValidationError` from `pydantic` in config.py.

    4. In tests/test_config.py, add a new test class `TestTomlStructureErrors` with:
       - `test_wrong_section_name_gives_helpful_error`: Write TOML with `[default]\ntitle = "Test Doc"`, assert `pytest.raises(ConfigError, match="profiles.default")`
       - `test_unknown_toplevel_section_error`: Write TOML with `[bogus]\nfoo = "bar"\n\n[profiles.default]\n`, assert `pytest.raises(ConfigError, match="bogus")`
       - `test_title_alias_works`: Write TOML with `[profiles.default]\ntitle = "My Doc"`, load, assert `settings.profiles["default"].default_title_template == "My Doc"`
       - `test_title_env_var_override`: monkeypatch `SANELESS_PROFILES__DEFAULT__TITLE` to "EnvTitle", load_settings(), assert default_title_template == "EnvTitle"

    IMPORTANT: Do NOT add `extra = "ignore"` to Settings. The extra=forbid behavior is correct for catching typos -- we just need to catch the error and provide a better message. Also do NOT suppress errors with `# type: ignore` or `# noqa`.
  </action>
