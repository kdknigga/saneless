When directory creation fails, skip the file handler and fall back to stderr-only logging (add a stderr handler unconditionally when file handler setup fails). Log a warning to stderr about the fallback. Structure:
   ```python
   try:
       Path(log_file).parent.mkdir(parents=True, exist_ok=True)
       file_handler = RotatingFileHandler(...)
       file_handler.setFormatter(formatter)
       root_logger.addHandler(file_handler)
   except (PermissionError, OSError):
       stderr_handler = logging.StreamHandler(sys.stderr)
       stderr_handler.setFormatter(formatter)
       root_logger.addHandler(stderr_handler)
       root_logger.warning("Cannot write to %s, logging to stderr only", log_file)
   ```
   Move the file_handler creation inside the try block so both mkdir AND file open failures are caught.
